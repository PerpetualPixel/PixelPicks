# PixelPicks

A standalone, low-overhead board for the day's Pixel's Picks — 3 to 10 bets a
day, tracked daily, with a focus on Tennis, NCAAF and NFL.

Data comes from the existing PerpetualCode Cloudflare Worker (the same one
behind [perpetualpicks.com](https://perpetualpicks.com)) via its public
read-only JSON endpoints — no API keys, no odds credits, no backend here.

See [PLAN.md](PLAN.md) for the architecture, courses of action, and the MVP
build plan.
